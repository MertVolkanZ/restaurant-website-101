# Restaurant Web Sitesi

Software Persona - Web Geliştirme; Yapay Zeka projesi kapsamında geliştirdiğim restoran tanıtım sitesidir. Dünya mutfağından yemeklerin bulunduğu, mobil uyumlu ve çok dilli bir web sitesidir.

## Proje Hakkında

Bu projede kullanıcıların restoranın menüsünü inceleyebileceği, yemekleri kategorilere göre filtreleyebileceği ve restoran hakkında bilgi alabileceği bir web sitesi oluşturdum.

Site tanıtım amaçlıdır. Gerçek rezervasyon veya ödeme işlemi yapılmamaktadır.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- React 18
- LocalStorage

HTML ve CSS ile sayfanın genel yapısı oluşturuldu. JavaScript ile menü filtreleme, dil değiştirme, tema seçimi ve galeri gibi özellikler geliştirildi.

React ise yukarı dön butonunda kullanıldı.

## Özellikler

- Mobil ve masaüstü uyumlu tasarım
- Kategorilere ayrılmış restoran menüsü
- Daha Fazla Göster özelliği
- 6 farklı dil seçeneği
- Açık ve koyu tema
- Otomatik değişen ana sayfa görselleri
- Fotoğraf galerisi
- Mobil navigasyon
- Yukarı dön butonu

## Projeyi Çalıştırma

Projeyi bilgisayarda çalıştırmak için Node.js kurulu olmalıdır.

Terminal üzerinden:

```bash
npm install
npm run dev
```

Ardından tarayıcıdan `http://localhost:5500` adresine gidilebilir.
